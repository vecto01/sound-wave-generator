# План проекта: Интерактивный генератор звуковых волн с визуализацией

## Описание
Создание веб-приложения для генерации звуковых волн (синусоида, треугольник, пилообразная, шум) с визуализацией в реальном времени на Canvas/SVG.

## Фичи

### Базовые
1. **Генерация звука**:
   - Синусоида, треугольник, пилообразная, шум.
   - Регулировка частоты, амплитуды, фазы.
   - Плей/пауза.

2. **Визуализация**:
   - График волны на Canvas/SVG.
   - Регулировка цвета и толщины линии.

3. **UI**:
   - Темная и светлая тема (сохранение в localStorage).
   - Адаптивность для мобильных устройств.

### Дополнительные
4. **Экспорт**:
   - Экспорт аудио (WAV/MP3) и изображения.

5. **Анимации**:
   - Плавные переходы при изменении параметров.
   - Лоудер и анимации загрузки.

6. **Производительность**:
   - Оптимизация рендера волн.
   - Ленивая загрузка.
