# Интерактивный генератор звуковых волн с визуализацией

![Preview](preview.png)

## Описание
Веб-приложение для генерации звуковых волн (синусоида, треугольник, пилообразная, шум) с визуализацией в реальном времени.

## Демонстрация
- [GitHub](https://github.com/vecto01/sound-wave-generator)

## Фичи
- Генерация звука с регулировкой частоты, амплитуды, фазы.
- Визуализация волны на Canvas.
- Темная/светлая тема.
- Адаптивный интерфейс.

## Установка
Просто откройте `index.html` в браузере.

## Использование
1. Выберите тип волны (синусоида, треугольник, пилообразная, шум).
2. Настройте параметры с помощью слайдеров.
3. Нажмите "Play" для воспроизведения.

## Технологии
- HTML5 Canvas
- Web Audio API
- CSS3
